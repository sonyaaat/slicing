Below are observations about user messages from this collection. The
messages come from several different topic areas.
Group LOW: messages where two different assistants later answered poorly.
Group HIGH: messages where they answered well. You never see the answers.

Propose 5-8 ATTRIBUTES of the messages that could separate the groups.

An attribute is a question about a message with 2-6 mutually exclusive
values plus "other". It describes the situation the message is about: who
is involved, what is happening to whom or to what, what is known about it,
and what is being asked for. It must NOT describe how the message is
written: its length, the number of questions, grammar, politeness,
formatting, or which particular words are used. A non-expert must be able
to check the value from the message in under a minute. If deciding the
value would require knowing what a good answer should contain, the
attribute is not allowed.

Universality. The attribute must make sense for every message shown,
whatever its topic area. A value that means something is not stated
("age not stated") is a valid value, not a reason to skip the message.

Naming. The name is 1-3 plain words that say what is being checked
("patient age", "who writes", "symptom onset"). Values are short facts
about the situation ("child", "adult", "not stated"), not descriptions of
wording ("child words present"). Test: a person with no training in the
field must understand the name and every value without any explanation;
if a value needs a footnote, rename it or drop it. No abstract nouns, no
jargon unless the user used the word.

Grounding. For every value give at least 2 prompt_ids from the data above,
from at least 2 different messages that look like they come from different
topic areas, each with a short quote (empty quote allowed for
"not stated" values). Values without 2 grounded examples are not allowed.
